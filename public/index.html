❓ FAQ

Kann ich mit Bedrock spielen?

Ja. Verbinde dich mit derselben Adresse. Dein Name bekommt einen Punkt davor.

Wie verdiene ich Stars?

In der AFK-Zone (/afk), per Kill und beim Abbauen von Erzen im Farm-Modus (/farmmode).

Wie bekomme ich einen Rang?

Die Ränge PREMIUM bis VIP gibt es im Gem-Shop. Alle Vorteile stehen in der Wiki.

Wann gibt es Keys für alle?

Jede Stunde bekommt jeder Online-Spieler automatisch einen Key (Keyall).

Ich habe einen Bug gefunden

Melde ihn im Discord an das Team. Bugs auszunutzen ist verboten.
